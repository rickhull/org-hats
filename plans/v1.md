# org-hats v1.1 — remaining work

**Status:** Forward plan. `v1.0.0` is historical and frozen; `1.1.0` is the
current target and a coordinated break with the sole consumer. What exists is
documented in `docs/`; history is in commit messages. The v0.4 line is
frozen on `main` at its tags.

## Constraints

- `1.0.0` receives no patches. Fixes and cleanup land in `1.1.0`.
- `1.1.0` may break the 1.0 shape. Quartermaster is the sole consumer and
  reviews the break; there is no compatibility layer for the old spelling.
- 1.1 remains the portable package only: the model, authority runtime with
  the in-memory adapter, neutral access verifier, conformance inventory, and
  pilot. The Cloudflare implementation and demo are a separate 0.x package.
- Distribution is by git tag only; no registry publication until a second
  consumer asks. Tags are immutable.
- The portable fence is law: `src/` compiles with `types: []` and imports
  nothing Cloudflare or Node-only.
- Quartermaster accepts authority interface `1` and access envelope `1`.
  Interface changes within 1.x are either additive or an explicit 1.x break
  agreed with the consumer.
- No customer names, real rosters, or real-person data in this repository;
  the twins and conformance fixtures are synthetic.

## B1 — The 1.1.0 break

- [x] **Id naming.** `Organization.id` is `Organization.organizationId`,
  matching the `(organizationId, actorId)` pair and grant/participant refs.
- [x] **`participation-accept`.** Takes `{ operationId }` only; the
  unreachable `{ invitationId }` form is gone.
- [x] **In-memory defaults.** `createInMemoryAuthority` uses the wall clock,
  gives each default signer a distinct key id, and keeps `tests` on an
  injected fixed clock. The public signer type no longer exposes
  `privateKey()`.
- [x] **Declaration specifiers.** `bin/fix-dts.mjs` rewrites emitted `.d.ts`
  imports to `.js`; `bin/check` refuses a `.ts` specifier in `dist/`.
- [x] **Migration note.** `docs/migration-v1.md` records the 1.0 → 1.1
  deltas.
- [ ] **Consumer proof.** Quartermaster moves from `1.0.0` to `1.1.0`,
  changes `organizations[].id` to `.organizationId`, and typechecks/tests
  against the new pin. *Acceptance:* their build is green on 1.1; a consumer
  with `skipLibCheck: false` typechecks.

## M6 — `org-hats-cloudflare`

## Risks

| Risk | Impact | Mitigation |
| --- | --- | --- |
| 1.1 break arrives while Quartermaster is building | High | Sole consumer; ship the break before more consumer code; migration note and their proof run are part of acceptance |
| M6 Durable Object scope balloons | Medium | Separate 0.x package; split tasks; never gates the portable line |
| Policy vocabulary grows into a general policy language | Medium | Conformance/twin-driven only; reject what the cases do not exercise |
| Consumer contract drift | Medium | Reconcile against Quartermaster's specs each turn; record accepted versions |
| Workerd/foreign-binary friction | Medium | Ed25519 is proven; extend the thinkpad `nix-ld` libraries if another binary fails; no per-project FHS wrapper |
