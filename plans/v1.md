# org-hats v1 — remaining work

**Status:** Forward plan. The portable line has reached its alpha; this file
names only what remains. What exists is documented in `docs/`; history is in
commit messages. The v0.4 line is frozen on `main` at its tags.

## Constraints

- 1.0 is the portable package only: the model, authority runtime with the
  in-memory adapter, neutral access verifier, conformance inventory, and
  pilot. The Cloudflare implementation and demo are a separate 0.x package.
- Distribution is by git tag only; no registry publication until a second
  consumer asks. Tags are immutable.
- The portable fence is law: `src/` compiles with `types: []` and imports
  nothing Cloudflare or Node-only.
- Quartermaster accepts authority interface `1` and access envelope `1`.
  Changes after the release tag are additive or re-reviewed.
- No customer names, real rosters, or real-person data in this repository;
  the twins and conformance fixtures are synthetic.

## Risks

| Risk | Impact | Mitigation |
| --- | --- | --- |
| Interface churn after 1.0 | High | Additive-only; breaking changes re-review with Quartermaster |
| M6 Durable Object scope balloons | Medium | Separate 0.x package; split tasks; never gates the portable release |
| Policy vocabulary grows into a general policy language | Medium | Conformance/twin-driven only; reject what the cases do not exercise |
| Consumer contract drift | Medium | Reconcile against Quartermaster's specs each turn; record accepted versions |
| Workerd/foreign-binary friction | Medium | Extend the thinkpad `nix-ld` libraries; no per-project FHS wrapper |
